# Phase 1 – Brainstorming & Ideation

## Problem Statement
Managing budgets for different life needs (home decor, events, jewelry) is overwhelming because of the huge variety of
products, platforms and price ranges. People overspend or waste hours comparing options across Amazon, Flipkart, IKEA,
Swiggy, Zomato, OYO, etc.

## Idea
**PocketSmart AI** – a GenAI-powered assistant that takes a user's budget, preferences and context (text and optional
images) and returns curated, budget-aware recommendations from multiple platforms.

## Brainstormed Ideas
| Idea | Description | Selected |
|------|-------------|----------|
| Home Budget Planner | Room-wise furniture/lighting/decor suggestions within budget | Yes |
| Party Budget Planner | Splits budget across catering, decoration, entertainment, venue | Yes |
| Jewelry Budget Planner | Occasion + outfit-image based jewelry suggestions | Yes |
| Generic expense tracker | Only tracks spending, no recommendations | No |

## Target Users
Homemakers, students, event organizers, shoppers and anyone planning purchases within a fixed budget.

## Scenarios
1. **Home Interior Planning** – choose rooms and quantities (lights, fans, tables) -> AI recommends cost-effective items.
2. **AI Party Planning** – budget, guest count, event type, venue -> proportional allocation to catering/decor/entertainment.
3. **Jewelry Recommendation** – budget, occasion, style (+ outfit image) -> matching jewelry options.

## Unique Value
One platform, three planners, multimodal AI, multi-platform sourcing, personalised history.
